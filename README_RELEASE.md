# LumiField v1.1.44

LumiField v1.1.44 is a GPL-3.0-only Windows release focused on reliable
interaction, portable presets, richer playback controls and smoother visual
rendering.

## Download

Use only `LumiField-1.1.44-Setup.exe`. Verify it against `SHA256SUMS` and
`RELEASE_MANIFEST.json` before installing.

## Highlights

- Audio Echo now remains visible through the main-interface gaps and preserves
  the intended layer order in the secondary stage.
- Long-press climax preview uses one player, exact repeat boundaries and safe
  queue/playback restoration; the sleep timer uses absolute deadlines.
- Windows taskbar media controls, integrity-warning acknowledgement and preset
  share codes now use hardened main-process boundaries.
- Electronic Pet 2 ships from a fixed local AGPL source snapshot with complete
  corresponding source, notices and deterministic build provenance.
- Full-app scheduling, wallpaper/video work, search/playlist interaction and
  startup rendering received measurable performance reductions.
- The removed golden-star preset remains absent; its owner-origin provenance is
  retained only as historical evidence.

## Requirements

- Windows 10 or Windows 11 x64
- Network access for online music and weather services
- A microphone and Windows speech support only when voice wake is enabled

## Important

- LumiField is not an official client of any supported music platform.
- Music-platform functionality requires the user's own lawful account and
  remains subject to platform terms and content rights.
- The primary installer is the LumiField music application; the separately
  scoped monitor setup is not a primary release asset.
- v1.1.43 remains frozen and its published assets are not replaced by v1.1.44.

Source, build instructions, GPLv3 text, third-party notices, corresponding AGPL
source and modification records are included in the repository and source
archive.
