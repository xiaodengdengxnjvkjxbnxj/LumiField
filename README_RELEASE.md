# LumiField v1.1.43

LumiField v1.1.43 is the first full V4 public release candidate: an immersive Windows music player with dynamic lyrics, audio-reactive visuals, 3D playlists, weather radio and locally scoped account state.

## Download

Use only `LumiField-1.1.43-Setup.exe`. Verify it against `SHA256SUMS` and `RELEASE_MANIFEST.json` before installing.

## Requirements

- Windows 10 or Windows 11 x64
- WebView/network access for online music/weather services
- A microphone and Windows speech support only when voice wake is enabled

## Important

- LumiField is not an official client of any supported music platform.
- Music-platform functionality requires the user's own lawful account and remains subject to platform terms and content rights.
- The installer is the LumiField music application; the separate monitor setup is not a primary release asset.
- `v1.0.10` and earlier installers should not be installed or redistributed.

Source, build instructions, GPLv3 text, third-party notices and modifications are included in the repository and source archive.
