# LumiField website design context

## Direction

Dark, immersive music space with restrained cyan and violet light. Typography is editorial at section scale and technical in provenance/status surfaces. Interaction should feel immediate and spatial without competing with product information.

## Required behavior

- Preserve the current LumiField identity and v1.1.43 frozen release facts until the next release exists.
- Lazy-load non-first-screen visual code and keep only one effect instance alive.
- Retain keyboard focus, mobile layout, reduced-motion support, and visible status feedback.
- Keep all runtime assets local; no external CDN, iframe, telemetry, or cookies.
- Show both sponsor codes directly in the support section.
- Record upstream effect source, pinned commit, license, hashes, and wrapper modifications.

## Avoid

- A white/minimal static landing page.
- Simultaneously running effects.
- Decorative controls that do not work.
- Unverified release or compatibility claims.
