# 21st Marketplace component-code license evidence

Reviewed: 2026-08-13

Official 21st Community documentation states that Marketplace components are
open-source under the MIT license and may be used in any project:
<https://21st.mintlify.app/community>.

The 2026-08-13 response was 318,141 UTF-8 bytes with SHA-256
`D24C882F6BB8FCDD4D4AD27261D85F80599B94C1CB9A988426379FD4DD5517C5`.

The current Marketplace Terms, <https://21st.dev/terms>, separately preserve
author ownership and distinguish underlying component code from Marketplace
demos, previews, screenshots, videos, media and structured metadata. They also
require a clear, visible link to the original component page when a component
is redistributed. The 2026-08-13 response was 63,872 UTF-8 bytes with SHA-256
`D30851B33249A5661CF926A0366A52B0C9FBB2663E71CE389A14E63A64866218`.

Accordingly, the fixed underlying component expression directly adapted into
LumiField is classified `MIT_OR_PERMISSIVE_PASS` when all of the following are
preserved:

1. component author, name and original 21st page link;
2. the MIT license text in `resources/licenses/21st-Marketplace-Components-MIT.txt`;
3. the exact supplied/live source identity and hash recorded in the component
   source record;
4. a clear statement of LumiField modifications;
5. exclusion of 21st-owned demos, preview pages, screenshots, videos, media and
   structured Marketplace metadata from the release package.

This evidence covers the underlying code of the five direct adaptations:

- `reuno-ui/shader-svg`;
- `minhxthanh/interactive-neural-vortex-background`;
- `xordev/atc-shader`;
- `satoriui/kinetic-grid` (also exposes an item-level MIT declaration);
- `jatin-yadav05/vapour-text-effect`.

It does not grant rights to reference videos or other third-party media, which
remain evidence-only and are not packaged.
