# Release gate

| Item | Status | Release condition |
|---|---|---|
| LumiField independent animated-search implementation | `NOT_BLOCKED_BY_UPSTREAM_LICENSE` | Keep the independent-implementation boundary and this provenance record. |
| Copy/adaptation of the unavailable 21st.dev implementation | `LICENSE_BLOCKED_UPSTREAM_COPY` | Obtain and retain the exact source version plus a license/grant compatible with the intended distribution before importing any upstream expression. |
| User-supplied reference video/TXT | `REFERENCE_ONLY_NOT_PACKAGED` | Do not package them unless separate distribution rights are confirmed. |

This component-specific upstream gate must not stop private development, testing,
or distribution of LumiField's independently authored replacement.
