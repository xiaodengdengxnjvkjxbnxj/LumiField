# Release gate

| Item | Status | Release condition |
|---|---|---|
| LumiField independent animated-weather implementation | `LF_INDEPENDENT_IMPLEMENTATION_NOT_BLOCKED` | Retain the independent implementation and this provenance record. |
| Copy/adaptation of the 21st.dev component | `LICENSE_BLOCKED_UPSTREAM_COPY` | Obtain and retain a specific source version plus a license or written grant compatible with the intended distribution before importing upstream expression. |
| User-supplied TXT/video | `REFERENCE_ONLY_NOT_PACKAGED` | Do not package these reference files unless separate distribution rights are confirmed. |

The upstream-copy gate does not stop private development, testing, or public
release of LumiField's independently authored replacement.
